# Increase test coverage to 100%

## Overview

Take caret from the measured baseline of **52.02%** line coverage
(9,842 / 18,919 trackable lines, covr with `NOT_CRAN=true`, 2026-08-16) to
**100%**, including `src/caret.c`, with no `# nocov` exclusions. Work is
executed in 9 stages; each stage ends with a stop for inspection, commit, and
PR (no commits are made by the assistant). Dead or buggy code discovered along
the way gets a minimal source fix plus an `inst/NEWS.Rd` entry in the same
stage (as in #1473/#1476/#1479).

Conventions for all test work:

- `expect_snapshot(error = TRUE)` / `expect_snapshot_warning()` — never
  `expect_error(regexp=)` / `expect_warning(regexp=)`; snapshots for printed
  output unless it is stochastic (timestamps, timings).
- No code in test files outside `test_that()`; shared fixtures/functions live
  in `helper-*.R`.
- Test file names mirror `R/` source file names.
- `expect_named()` / `expect_s3_class()`, not `expect_equal()` on
  names/classes (matrix dimnames: `expect_identical(colnames(x), ...)`).
- `expect_all_true()` / `expect_all_false()` / `expect_all_equal()`, not
  `expect_true(all(...))` / `expect_false(any(...))`.
- No stray console output from `devtools::test()`.
- Existing seeds stay; new tests use random integers in 1–10000
  (`withr::local_seed()` or `set.seed()` inside `test_that()`).
- `skip_on_cran()` on every model-fitting test; `skip_if_not_installed()`
  (double quotes) per optional package.
- `air format` on every modified R file.
- Where a function has x/y, formula, and recipe interfaces, test all three.

- caret passes `lev = NA` (not `NULL`) for a numeric outcome, so a custom model

  missing (this is caret#1516).
- `expect_snapshot_warning()` records only the first warning. These scenarios
  raise two (the failed resample, then the missing-values notice), so they need
  `expect_snapshot()`.

Also fixed a pre-existing flaky test: `test-train.default-sparse.R` fits glmnet
without a seed, and glmnet warns when a lambda does not converge — which depends
on the resampling draw. The test's own `expect_no_warning()` calls were therefore
a lottery, and adding tests elsewhere (which shifts the RNG stream) made it warn.
It is now seeded.
