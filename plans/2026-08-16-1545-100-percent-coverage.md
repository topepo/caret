# Increase test coverage to 100%

## Overview

Take caret from the measured baseline of **52.02%** line coverage
(9,842 / 18,919 trackable lines, covr with `NOT_CRAN=true`, 2026-08-16) to
**100%**, including `src/caret.c`, with no `# nocov` exclusions. Work is
executed in 9 stages; each stage ends with a stop for inspection, commit, and
PR (no commits are made by the assistant). Dead or buggy code discovered along
the way gets a minimal source fix plus an `inst/NEWS.Rd` entry in the same
stage (as in #1473/#1476/#1479).

Conventions for all test work:

- `expect_snapshot(error = TRUE)` / `expect_snapshot_warning()` — never
  `expect_error(regexp=)` / `expect_warning(regexp=)`; snapshots for printed
  output unless it is stochastic (timestamps, timings).
- No code in test files outside `test_that()`; shared fixtures/functions live
  in `helper-*.R`.
- Test file names mirror `R/` source file names.
- `expect_named()` / `expect_s3_class()`, not `expect_equal()` on
  names/classes (matrix dimnames: `expect_identical(colnames(x), ...)`).
- `expect_all_true()` / `expect_all_false()` / `expect_all_equal()`, not
  `expect_true(all(...))` / `expect_false(any(...))`.
- No stray console output from `devtools::test()`.
- Existing seeds stay; new tests use random integers in 1–10000
  (`withr::local_seed()` or `set.seed()` inside `test_that()`).
- `skip_on_cran()` on every model-fitting test; `skip_if_not_installed()`
  (double quotes) per optional package.
- `air format` on every modified R file.
- Where a function has x/y, formula, and recipe interfaces, test all three.

Stage 3 outcome notes:

- Source fix (with NEWS entry): `preProcess(method = "corr")` promised to add
  a zero-variance filter but never did — the check ran after `method` had been
  turned from a character vector into a named list, so it tested the list's
  values instead of its names. A zero-variance predictor then made the
  correlation matrix undefined and the call failed with "missing value where
  TRUE/FALSE needed". Found by the new verbose test.
- Snapshot masking moved to a shared `helper-snapshots.R` holding
  `mask_decimals()` (from helper-collinearity.R) and a new `mask_env()` for
  printed formula environments, whose addresses change every session. The
  pre-existing inline transform in test-dummyVar.R now uses it too.
- `pre_process_options()` takes the coarse type strings from `get_types()`
  ("numeric"/"string"/"other"), not a logical vector — worth remembering when
  calling it directly.
- `preProcess(method = "corr")` on a single predictor errors out of
  `findCorrelation` ("only one variable given") rather than treating the
  filter as a no-op. Characterised by a snapshot test; worth deciding whether
  it should degrade gracefully.
- Verification lesson: `as.data.frame(testthat::test_file(...))` reports
  errors in an `error` column, not `failed`. Check both — a test of mine
  erred silently for several runs because only `failed` was being printed.

Open question for the maintainer — `checkInstall()`'s interactive branch
(R/modelLookup.R:121-141, 16 lines) cannot be reached from tests:
`interactive()`, `menu()`, `install.packages()` and `source()` are all base or
utils functions with no binding in caret's namespace, so
`local_mocked_bindings()` refuses to mock them. Covering it needs small
mockable seams in the source. Separately, that branch's Bioconductor path
calls `source("http://bioconductor.org/biocLite.R")`, which Bioconductor
retired in 2019, so it would fail if a user ever reached it.
